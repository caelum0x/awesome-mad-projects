infinity-lab

Turning anime, pop-culture and pure-math ideas into real, tested code.

A small monorepo that takes fictional and folk-mathematical claims — Gojo’s Infinity, the Central Finite Curve — seriously enough to build them, run them, and test them as honest mathematics.

Where the math genuinely holds, the code proves it; where it can’t hold, the code says so plainly instead of pretending.

Honest caveats

The parts where the mathematics can’t hold — stated up front, because the code says so too.

Where the math bends, and where it breaks

  • The Möbius strip is a ruled surface, so its Gaussian curvature is strictly negative (K < 0) everywhere on the interior — it never vanishes. That is precisely why the Central Finite Curve has to be R’s zero set (K·R = 0 ⇔ R = 0): the curvature can’t supply the sign change, so R does.
  • Gojo’s Infinity is only fragile at true infinity: every finite Zeno residual (1/2)n > 0 is strictly positive, and the Formidable reading rests on an improper integral that diverges only in the limit — not at any finite step.
  • Applying real analysis to a fictional universe has limits. ‘Cursed energy’ and authorial intent are not governed by real analysis. These models illuminate the ideas of Infinity and the Central Finite Curve — they do not govern them.
