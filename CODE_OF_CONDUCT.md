# Code of Conduct

This project is a small, friendly, curiosity-driven collection. To keep it that way, everyone
taking part — maintainers, contributors, and commenters — agrees to a few simple things.

## Be decent

- Be respectful and welcoming. Assume good faith. Critique ideas and code, not people.
- No harassment, discrimination, personal attacks, or demeaning comments — in issues, pull
  requests, commits, or any project space.
- Keep it about the work: the mathematics, the code, and whether it runs.

## Be honest

- Represent what your code does accurately. If something is a simulation, a metaphor, or
  doesn't quite work, say so.
- Only contribute original code and original art, and respect other people's copyright and
  licenses. Cite the sources you build on.

## Scope

This applies to all project spaces (the repository, issues, pull requests, and any official
channels) and when representing the project in public.

## Enforcement

If you see behavior that breaks these expectations, contact the maintainer at
**caelum0x42@gmail.com**. Reports will be reviewed and handled
privately and in good faith. Maintainers may edit, hide, or remove contributions and comments
that violate this code, and may block repeat offenders from participating.

We'd rather have a small, kind community than a large, unpleasant one.
