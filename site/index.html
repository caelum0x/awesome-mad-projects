Section 3 — Open source

Community collection

Awesome MIT License PRs Welcome 22 Projects 9 Python packages 600+ Tests

awesome-mad-projects is a curated, open-source collection. Every project has an honest mathematical or systems core — a real theorem, metric, or geometry doing the work. Where the real thing would be unsafe (OS-level process control, filesystems, kernel drivers), the code stays in safe userspace over a sandbox it creates and owns. Anime and pop-culture provide the motivation; mathematics provides the substance.

Step 01

Fork the repository

Fork on GitHub and clone locally. The repo is a monorepo — each project lives in its own top-level folder.

Step 02

Add your project

Create a folder with a README.md and a test suite. Add an entry in site/projects.json and a cover image in site/assets/covers/. Read the CONTRIBUTING guide for the schema.

Step 03

Open a pull request

Submit your PR against main. If you have an idea but no code yet, open an issue to discuss it first.

Section 4 — Caveats

Honest caveats

Where the math cannot hold, the code says so. These are analogies and simulations, not claims about reality.

  • The ruled surface has K < 0 everywhere. The Möbius / Central-Finite-Curve zero set is a genuine ruled surface, so its Gaussian curvature is strictly negative. It is a beautiful saddle, not a magical loop — the geometry is honest, the mythology is not.
  • True infinity is fragile. The infinite-hotel scheduler and Gojo's “Infinity” (Sₙ = 1 − (1/2)ⁿ as n → ∞) work as limits and countable re-indexings only. Push them to literal, actualized infinity in finite memory and they break — the code models the paradox, it does not resolve it.
  • Cursed energy is not governed by real analysis. Domain Expansion, Unlimited Void, and the Stand system dramatize constraint solving, container isolation, and scheduling. They are safe, sandboxed simulations over process tables the tools create and own — no anime physics is claimed.
  • Thermodynamic and paradox pieces are caricatures. Madoka's karmic entropy (ΔS ≥ 0), Zeno's transport (1/2 + 1/4 + … = 1), and Banach–Tarski's duplication (m(Z) = 0 for the free-group set) each capture one true idea and deliberately ignore the rest of the physics.

Mathematics after Achmad Roykhan Sabiq, whose essay for the Oxford Mathematics Essay Competition 2026 inspired the infinity-lab work. Attribution and summary only — no essay prose is reproduced here. Essay PDF ↗
