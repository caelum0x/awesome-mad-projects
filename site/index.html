Honest caveats

Where the math can't hold, the code says so. These are analogies and simulations, not claims about reality.

  • The ruled surface has K < 0 everywhere. The Möbius / Central-Finite-Curve zero set is a genuine ruled surface, so its Gaussian curvature is strictly negative. It is a beautiful saddle, not a magical loop — the geometry is honest, the mythology is not.
  • True infinity is fragile. The infinite-hotel scheduler and Gojo's “Infinity” only work as limits and countable re-indexings. Push them to literal, actualized infinity in finite memory and they break — the code models the paradox, it does not resolve it.
  • Cursed energy is not governed by real analysis. Domain Expansion, Unlimited Void, and the Stand system dramatize constraint solving, container isolation, and scheduling. They are safe, sandboxed simulations over process tables the tools create and own — no anime physics is claimed.
  • Thermodynamic and paradox pieces are caricatures. Madoka's karmic entropy, Zeno's transport, and Banach–Tarski's duplication capture one true idea each (an entropy budget, a geometric series, a free-group paradox) and deliberately ignore the rest of the physics.
